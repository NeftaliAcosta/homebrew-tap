# Homebrew Tap for Aurae

Official Homebrew Tap for [Aurae](https://github.com/NeftaliAcosta/Aurea) — Intelligent, 100% local, native voice dictation for macOS.

## Installation

```bash
brew install --cask neftaliacosta/tap/aurae
```

Or add the tap first:

```bash
brew tap neftaliacosta/tap
brew install --cask aurae
```

## Requirements

- macOS Ventura (13.0) or later
- Apple Silicon Mac (M1/M2/M3/M4)
